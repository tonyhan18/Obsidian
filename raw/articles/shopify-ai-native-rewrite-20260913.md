# Shopify, AI 에이전트로 Shop 앱을 12주 만에 네이티브로 전환

## 요약
핵심 엔지니어 6명이 코딩 에이전트와 함께 React Native 앱을 Swift와 Kotlin으로 재구축했으며, 기능별 팀의 검증을 거쳐 개념 증명부터 앱스토어 출시까지 12주가 걸림.

## 핵심 내용
- React Native의 New Architecture 도입을 검토하던 중, 에이전트가 iOS와 Android를 따로 개발하는 비용이 더 낮다고 판단
- 6명의 핵심 엔지니어 + 코딩 에이전트 조합으로 네이티브 재구축
- 기능별 팀의 검증(verification) 거쳐 품질 관리
- 개념 증명(POC)부터 앱스토어 출시까지 12주
- AI 에이전트가 크로스플랫폼 vs 네이티브의 기술적 의사결정까지 영향
