# Google에 더 나은 모습을 기대했다 - 코드는 가져가고 출처는 지운 Artemis

- **소스:** GeekNews (https://news.hada.io/topic?id=33587)
- **수집일:** 2026-09-13

## 요약
Minitap 팀이 Google의 모바일 자동화 프로젝트 Artemis에서 자신들이 만든 mobile-use 코드를 발견했지만, 원래 프로젝트와 개발자에 대한 출처 표기는 찾을 수 없었음. Android 연결 코드와 에이전트 지침, WhatsApp 예제가 일치했으며, 이전 버전에는 같은 버그까지 재현됨.

## 핵심 포인트
- Google Artemis가 오픈소스 mobile-use 코드를 출처 표기 없이 사용
- Android 연결 코드, 에이전트 지침, WhatsApp 예제 일치
- 이전 버전 동일 버그 재현 → 동일 코드 사용의 강력한 증거
- 기존 [[google-gemini-windows-artemis-20260911]]의 ARTEMIS에 대한 후속 이슈
