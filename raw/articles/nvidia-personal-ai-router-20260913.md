# NVIDIA Personal AI Router - 여러 컴퓨터에 로컬 AI 요청을 나눠 보내는 도구

## 요약
같은 네트워크의 컴퓨터들을 연결해 여러 앱과 에이전트의 AI 요청을 분산 처리하는 로컬 추론 라우터.

## 핵심 내용
- Ollama와 LM Studio를 지원
- OpenAI/Ollama 호환 API로 기존 앱과 에이전트를 연결 가능
- 실행 가능한 추론 엔진과 모델이 있는 컴퓨터 중에서 현재 부하가 가장 적은 곳으로 요청 분산
- 로컬 네트워크 기반 분산 추론 → 클라우드 API 의존 감소
- 개인/소규모 팀의 로컬 AI 인프라 구축 도구
