# 모델 가중치 공개 의무화 공개서한

## 정의
다리오 아모데이의 AI 개발 속도 조절 제안에 대한 대안으로, 외부 평가자와 복잡한 규제 대신 대중에게 제공하는 AI 모델의 가중치(weights) 공개를 법으로 의무화하자는 공개서한. 독점 모델 판매 기대가 기업가치와 대규모 투자를 떠받치고 있으므로, 가중치 독점을 없애야 경쟁과 투명성이 확보된다고 주장.

## 핵심 내용

### 서한의 구조적 논리
- **문제 진단:** AI 기업의 가중치 독점이 기업가치·대규모 투자의 핵심 기반
- **해결책:** 대중 제공 모델의 가중치 공개를 법적 의무화
- **기대 효과:** 독점 해소 → 경쟁·투명성·외부 검증 자연스럽게 확보
- 속도 조절·외부 평가·복잡한 규제보다 구조적 해법이 효과적

### 아모데이 제안과의 대비
- 아모데이: 안전성 투자 + 속도 조절 → 기업 자율 규제 프레임
- 공개서한: 가중치 공개 의무화 → 구조적 투명성 강제
- [[amodei-slow-ai-development-20260913|아모데이 속도 조절 제안]]이 자율 규제에 의존하는 한계 지적

## 분석

### 투명성 vs 안전성의 경로 차이
- [[ai-safety-alignment|AI 정렬과 안전성]] — 안전성 연구 중심 접근
- 가중치 공개는 외부 연구자가 모델 내부를 직접 검증할 수 있는 구조적 경로
- [[openai-research-trust-20260911|OpenAI 연구 신뢰 위기]] — 비공개 연구 정보 독점의 신뢰 위기에 대한 구조적 해법
- [[anthropic-activist-surveillance-20260910|Anthropic 예측형 감시]] — 안전성 표방 기업의 내부 통제 vs 외부 투명성 강제

### 시장 경쟁 관점
- 가중치 공개 → 경쟁사가 동일 모델을 사용 가능 → 차별화 압력 증가
- 오픈소스 AI(Mistral, Llama 등)와 독점 모델(OpenAI, Anthropic)의 구조적 대립 심화
- [[mistral-funding-20260908|Mistral 30억 유로 투자]] — 오픈소스 접근의 시장 검증

## 미해결 질문
- 가중치 공개 후 경쟁사가 미세 조정(fine-tune)하여 경쟁 모델을 만드는 것을 어떻게 막을 것인가?
- 공개된 가중치가 악의적 사용자에게 제공되는 리스크는?
- 법적 의무화의 관할 — 국가별로 분산되면 실효성 부족
- "대중에게 제공하는 모델"의 범위 — API만 제공하는 경우 포함 여부
